## Single View, No Split Panes

**Category:** ux

**Outcome:** Every screen is legible in a narrow terminal column - nothing is ever squeezed into a side panel that can't fit its content.

**Strategy:**
Navigate between full-width views (list to detail, detail back to list) rather than showing list and detail side by side. A "focused" or "drilled into" view replaces what's on screen; it never opens beside it.

**Rationale:**
The dashboard's primary use case is running next to an active Claude Code session, not full-screen - designing for full terminal width first would produce layouts that break in the actual usage context.
