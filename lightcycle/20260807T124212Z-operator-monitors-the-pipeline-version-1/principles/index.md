# Design Principles

- [Terminal-Native, No Server](terminal-native-no-server.md) - Installing and running the TUI feels like the rest of lightcycle - a single command, zero extra services to stand up or secure.
- [Observation Only](observation-only.md) - An operator can trust the TUI as a window onto the pool - nothing they do inside it can claim, close, unblock, or reconfigure a node.
- [Single View, No Split Panes](single-view-no-split-panes.md) - Every screen is legible in a narrow terminal column - nothing is ever squeezed into a side panel that can't fit its content.
- [One Navigation Contract](one-navigation-contract.md) - The operator never has to learn a new navigation scheme per screen; muscle memory from one view transfers to every other.
