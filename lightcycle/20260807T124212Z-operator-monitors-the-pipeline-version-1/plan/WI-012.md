## WI-012: Active items with elapsed time

**Brief:** Group active steps below needs-attention, each row showing an approximate running time
(computed by WI-005) and its current step name, live-updating without a full list refresh.

### Acceptance Criteria

Copied verbatim from the source story:

- Given an item is active, when it appears in the list, then its row shows an approximate elapsed time
  (e.g. '14m', '45s', '1h 7m'), not exact seconds.
- Given an item's elapsed time is displayed, when time passes, then the value updates periodically
  without a full list refresh.
- Given active items exist, when I view the list, then they're grouped below needs-attention and above
  queued, differentiated by their own label/icon/colour.
- Given a row's title is longer than one line, when it doesn't fit, then it wraps to a second line rather
  than being truncated with an ellipsis.
- Given an active item, when it appears in the list, then its current step name is shown alongside its
  elapsed time.

### Constraints

- Elapsed value sourced from WI-005's computation - this item does not compute elapsed time itself, only

- Uses the shared design-system tokens for icon/colour/grid.

### Verification

- Pilot test: an active fixture item renders with elapsed time, step name, correct icon/colour, grouped
  below needs-attention.
- Pilot test: elapsed time updates across two poll ticks without a full list re-render (only the changed
  cell updates).
