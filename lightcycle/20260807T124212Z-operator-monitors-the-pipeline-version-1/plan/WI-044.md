## WI-044: View a list artifact as a scrollable list

**Brief:** Render a `list`-kind artifact as its own scrollable `ListView`, distinct from the text viewer.
No real artifact in the live store currently produces this kind - `kind` is only ever set by explicit
declaration, never defaulted to `list` from any existing `type` - so verifying this item means manually
attaching a synthetic list-kind artifact, not exercising a real workflow path. Also carries this
artifact-viewer's own AC for closing back to the artifact list.

### Acceptance Criteria

Copied verbatim from "View a list artifact as a scrollable list":

- Given an artifact declares kind `list`, when I select it with Enter or →, then it displays as its own
  scrollable list rather than raw text.
- Given the list has more items than fit on screen, when I scroll, then I can reach every item.

Copied verbatim from "Return to the artifact list without losing position" (applies here since a list
artifact is a real TUI screen the operator sits in):

- Given I opened an artifact from the list, when I close it with Esc or ←, then the artifact list
  reappears with that artifact still selected.

### Verification

- Unit/Pilot test: a manually-constructed `list`-kind artifact fixture renders as a scrollable list, all
  items reachable when longer than one screen.

### Deliverable

exists in real data yet), with correct return-to-list behavior.
