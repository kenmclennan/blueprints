## WI-028: Land on the tab that matches the item's status

**Brief:** Opening a node selects its default tab by contextual rules: active → Log, needs-attention
human step or done → Artifacts, blocked-on-dependency/queued/theme → Hierarchy. This item establishes the
contextual-landing logic; Milestone 3/4 fill in the Artifacts/Log tabs' actual content afterward, but the
landing decision itself is fully specified and buildable now.

### Acceptance Criteria

Copied verbatim from the source story:

- Given the node is active (a worker is performing its current step), when I open it, then it lands on
  the Log tab.
- Given the node is a needs-attention item on a human step (e.g. await-merge, or rejected/needs rework),
  when I open it, then it lands on the Artifacts tab.
- Given the node is blocked on another item's completion, or is still queued/not yet run, when I open it,
  then it lands on the Hierarchy tab.
- Given the node is done, when I open it, then it lands on the Artifacts tab, same as a needs-attention
  item on a human step.
- Given the node is a theme, when I open it, then it lands on the Hierarchy tab, since a theme has no
  single item-level state of its own to key a different default off.

### Constraints

- **Confirmed against live code (2026-08-11): two distinct human/agent signals exist and must be
  reconciled, not conflated.** `Node.role` (drives `lane_for`'s inbox/queue split, via `role == "human"`)
  and `Flow.owner_of(step)` (drives `Node.classify_for_human`'s action/blocked split - returns the
  literal string `"human"` or the step's file identifier). The needs-attention bucket this item's AC-2
  keys off is the same one WI-011 (Priority List) already defines (`inbox` ∪ `blocked` lanes) - reuse
  that exact definition, do not derive a second one here from `Node.attention` (an unrelated manual
  triage flag).
- A theme has no `state`/`role` of its own to classify by - AC-5 is a fixed default, not a computed
  branch.

### Verification

- Pilot test: one fixture per AC (active, needs-attention-human, blocked-dependency, done, theme) opens
  onto the specified tab.
- Regression: the needs-attention classification used here matches WI-011's Priority List bucketing
  exactly for the same fixture data - no drift between the two.

### Deliverable

Every node type/state combination lands on the correct default tab.
