## WI-053: Filter the backlog by project via a picker

**Brief:** `f` opens an overlay picker listing "All" plus every registered project with its own item
count (sourced from WI-008's all-at-once read path), navigable with arrows. Enter applies the selection
and closes the picker; Esc cancels without changing the current filter. The filter bar shows only the
active filter's own count, never a breakdown of every project.

### Acceptance Criteria

Copied verbatim from the source story:

- Given I press f, when the picker opens, then it shows 'All' plus every registered project, each with
  its own item count, navigable with up/down.
- Given the picker is open, when I select a project and press Enter, then the backlog filters to only
  that project's items and the picker closes.
- Given the picker is open, when I press Esc, then it closes without changing the current filter.
- Given a filter is active (or 'All' is selected), when I look at the filter bar, then it shows only the
  current filter's own item count, not a breakdown of every project.
