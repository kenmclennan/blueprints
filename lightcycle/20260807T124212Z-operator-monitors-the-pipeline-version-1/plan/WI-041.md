## WI-041: View a text artifact full-screen + unknown-kind fallback

**Brief:** Render a `text`-kind artifact full-screen, scrollable. Since text is the universal fallback
renderer (every artifact value is a string at rest), any artifact declaring a kind the TUI doesn't
recognise also opens here rather than failing - this is what lets the engine avoid gatekeeping which
kinds a future workflow may express. Also carries this artifact-viewer's own AC for closing back to the
artifact list (a behavior common to text and list viewers, since URL/filepath hand off externally and
never sit in a TUI screen at all - see WI-042/043's own toast-and-return AC instead).

### Acceptance Criteria

Copied verbatim from "View a text artifact full-screen":

- Given an artifact declares kind `text`, when I select it with Enter or →, then it opens full-screen,
  scrollable if longer than one page.
- Given the text artifact is open, when I scroll, then I can read the whole thing without truncation.
- Given an artifact declares a kind the TUI does not recognise, when I select it, then it opens in the
  text viewer rather than failing, so no artifact is ever unopenable.

Copied verbatim from "Return to the artifact list without losing position" (applies here since a text
artifact is a real TUI screen the operator sits in):

- Given I opened an artifact from the list, when I close it with Esc or ←, then the artifact list
  reappears with that artifact still selected.

### Dependencies

- WI-040, WI-001 (the `kind` field this dispatch is keyed on).

### Constraints

- Rendering must be a total function over `kind` - never raise or show an error for an unrecognised
  kind, always fall through to this text view.
- Reuses the global Ctrl-U/Ctrl-D scroll convention (WI-014) for paging a long text artifact.

### Verification

- Pilot test: a `text`-kind artifact opens full-screen and scrolls without truncation.
- Pilot test: an artifact with an unrecognised kind value opens successfully in this same viewer, not an
  error.
- Pilot test: closing with Esc/← returns to the artifact list with the same artifact still selected.

### Deliverable

Text artifacts and any unrecognised-kind artifact render correctly, full-screen and scrollable, with
correct return-to-list behavior.
