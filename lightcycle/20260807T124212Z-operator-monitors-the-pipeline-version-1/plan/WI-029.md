## WI-029: Cycle tabs with `[` and `]`

**Brief:** Bind `]`/`[` to cycle Hierarchy → Log → Artifacts → Hierarchy (and reverse), deliberately
distinct from `Tab`'s existing global "jump to Backlog" meaning so the two never collide.

### Acceptance Criteria

Copied verbatim from the source story:

- Given a node's hub is open, when I press ], then the next tab in the Hierarchy → Log → Artifacts cycle
  becomes active.
- Given a node's hub is open, when I press [, then the previous tab in that cycle becomes active.
- Given a node's hub is open, on any tab, when I press Tab, then I jump straight to Backlog (or Current
  work), same as everywhere else - it never gets reinterpreted as a tab-cycle key.

### Source References

- **Artifact ID:** design-system/keyboard-navigation-scheme.md
- **Section:** "Why tabs use [ / ] and not Tab"
- **Excerpt:** "Tab is already the _global_ 'jump to Backlog, from anywhere, any depth' key. If it also
  cycled a node's tabs, the two meanings would collide the moment you wanted to jump to Backlog while a
  node was open - which one wins? `[`/`]` (a common previous/next-tab convention) keeps Tab's global
  meaning untouched in every context, including inside an open node."
- **Artifact ID:** wireframes/wireframe-hub.html
- **Section:** `#active-log`, `#hierarchy`
- **Excerpt:** `.tabs .hint { ... }` renders `[ / ]` as the visible hint next to the tab strip on every
  hub state; `#hierarchy` shows the same node (LC-143.3) with Hierarchy now active after cycling from
  Log.

### Dependencies

- WI-028 (a hub with a landed default tab to cycle from).

### Constraints

- `Tab`'s existing binding (established in Milestone 1/5's screen-switching, WI-051) must not be shadowed
  by this item's own bindings - both coexist unconditionally.

### Verification

- Pilot test: pressing `]` repeatedly cycles Hierarchy→Log→Artifacts→Hierarchy.
- Pilot test: pressing `[` cycles in reverse.
- Pilot test: pressing `Tab` from any of the three tabs jumps to Backlog/current-work, never changing the
  hub's own active tab first.

### Deliverable

`[`/`]` reliably cycle the hub's three tabs in both directions; `Tab` is unaffected.
