## WI-016: See a quiet message when there's no work at all

**Brief:** When all three buckets (needs-attention, active, queued) are empty, render a calm empty-state
message in place of the list. Clears automatically on the next poll that finds any row, riding the same
poll-and-diff loop as every other refresh - no bespoke live-update path.

### Acceptance Criteria

Copied verbatim from the source story:

- Given no items exist in any bucket, when the list renders, then a calm message is shown in place of the
  list, not a blank area.
- Given an item later enters any bucket, when that happens, then the message is replaced by the list
  showing that item.

### Dependencies

- WI-011, WI-012, WI-013 (all three groups must exist to detect "all empty").

### Constraints

- Message text is exactly "Nothing needs attention. Nothing's active. Nothing's queued." per the
  wireframe - this is a literal string, not paraphrasable.
- No new refresh mechanism - reuses WI-010's existing 10-second poll loop.

### Verification

- Pilot test: a fixture store with zero steps in any lane renders the exact empty-state message, not a
  blank list.
- Pilot test: a fixture transitioning from empty to having one queued item (across a simulated poll)
  replaces the message with the list.

### Deliverable

The priority list shows the calm empty-state message when genuinely empty, and clears it automatically
within one poll interval once any item appears.
