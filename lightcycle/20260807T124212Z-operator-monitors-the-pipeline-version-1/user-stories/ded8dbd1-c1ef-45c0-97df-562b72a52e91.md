## Return to the hierarchy tab without losing position

**Who:** Operator

**What:** Closing a node opened from the Hierarchy tab returns to that tab, at the same node still selected and scrolled to the same position.

**Why:** So I can keep exploring siblings without re-navigating from the root each time.

**Activity:** Inspect one item's journey - Understand a specific item end-to-end - its artifacts, child steps, and logs - to see what happened or why it's stuck.

**Step:** Explore the hierarchy

**Status:** ready

### Acceptance Criteria

- Given I opened a node from the Hierarchy tab, when I close it with Esc or ←, then the Hierarchy tab reappears with that node still selected and scrolled to the same position.
