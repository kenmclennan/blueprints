## See that a step has no live log to stream

**Who:** Operator

**What:** If the current step is human-performed (no worker), the view says so instead of showing an empty or broken pane.

**Why:** So I'm not left wondering if something's wrong.

**Activity:** Inspect one item's journey - Understand a specific item end-to-end - its artifacts, child steps, and logs - to see what happened or why it's stuck.

**Step:** Stream the current step's live log

**Status:** ready

### Acceptance Criteria

- Given the current step is a human step (no worker), when I try to open its live log, then I see a message saying there's nothing live to stream, not a blank or broken pane.
- Given the current step hasn't started yet (queued), when I try to open its live log, then the same message applies.
