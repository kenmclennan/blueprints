## Open the item detail view

**Who:** Operator

**What:** Selecting a row from the work list opens a full item-detail view.

**Why:** So I can see more than the list row shows, without losing my place in the list.

**Activity:** Inspect one item's journey - Understand a specific item end-to-end - its artifacts, child steps, and logs - to see what happened or why it's stuck.

**Step:** Find the item

**Status:** ready

### Acceptance Criteria

- Given the priority list is showing, when I select a row and press Enter or →, then the item's detail view opens, replacing the list on screen.
- Given the detail view has just opened, when it renders, then it shows the item's identity - id, title, owning project, theme (if it has one), and the workflow it's running under (if any).
- Given the item has a description, when the detail view renders, then the description is shown in the header, below the identity fields.
- Given the item has no description, when the detail view renders, then no description line is shown.
