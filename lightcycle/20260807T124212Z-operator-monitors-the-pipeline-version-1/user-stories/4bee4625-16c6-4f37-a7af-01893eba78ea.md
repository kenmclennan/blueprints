## See why an item is escalated

**Who:** Operator

**What:** For a needs-attention item, the detail view names the reason: an unmet dependency (with the ability to jump straight to that blocking item), an escalated step, or what a human step is asking of me.

**Why:** So I know what to do (or who to unblock) without having to dig for it, and can go straight to the thing actually holding this up.

**Activity:** Inspect one item's journey - Understand a specific item end-to-end - its artifacts, child steps, and logs - to see what happened or why it's stuck.

**Step:** Find the item

**Status:** ready

### Acceptance Criteria

- Given an item is blocked on a dependency, when I open its detail view, then it names the specific blocking dependency.
- Given an item's current step is escalated (e.g. rejected, needing rework), when I open its detail view, then it names what's being asked of me.
- Given an item is active or queued, not needs-attention, when I open its detail view, then no escalation reason is shown.
- Given an item is blocked on another item's completion, when I select the named blocking item with Enter or →, then I'm taken straight to that item's own detail view.
- Given I jumped to a blocking item's hub via that link, when I press Esc or ←, then I return to the original, blocked item's hub - not the priority list - at the tab I was on.

### Context

The node read surface this hub sits on (`Node.as_dict` / `NodeView`) only carries `deps` as a bare count - the store resolves which specific node blocks another only in its export path (`sqlite_store.py`'s `export_rows`), not in the hydration behind `lc show`/`lc claim`/`node_view` that a live hub would read from. Naming the blocking dependency and letting the operator jump straight to it (ac-1, ac-4) needs that specific blocking id surfaced on the live read path, which it isn't today. The human-step reason (ac-2) doesn't have this gap: `needs` is already populated as free text when a step routes to a human (`BlockStepUseCase` writes `"BLOCKED: %s" % needs`), so that half of the story already has a live field to draw on.
