## Jump straight to a node's artifacts or log from the hierarchy

**Who:** Operator

**What:** Pressing a or l on a node highlighted in the Hierarchy tab (not yet opened) opens its Artifacts or Log tab directly, skipping the contextual-default landing.

**Why:** So checking a lot of nodes quickly doesn't mean landing on the default tab and cycling for every one.

**Activity:** Inspect one item's journey - Understand a specific item end-to-end - its artifacts, child steps, and logs - to see what happened or why it's stuck.

**Step:** Explore the hierarchy

**Status:** ready

### Acceptance Criteria

- Given a node is highlighted in the tree, when I press a, then its artifact list opens directly.
- Given a node is highlighted in the tree, when I press l, then its log opens directly - live if it's the active step, past/historical if it's done.
- Given the highlighted node is a human step or hasn't run yet, when I press l, then the shortcut is a no-op, consistent with there being no log content to show.
