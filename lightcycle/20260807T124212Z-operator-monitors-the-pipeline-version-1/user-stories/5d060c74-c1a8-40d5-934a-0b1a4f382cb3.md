## Hear an alert when something needs me

**Who:** Operator

**What:** A terminal bell fires the moment an item enters the inbox or blocked bucket, even without the dashboard in focus.

**Why:** So I don't have to be looking at the screen to know something needs me.

**Activity:** Get oriented on the pipeline - See the whole pipeline at a glance - what's active, blocked, waiting on me, and queued - the moment it changes, as long as the dashboard is running.

**Step:** Review current work status

**Status:** ready

### Acceptance Criteria

- Given an item enters the inbox or blocked bucket, when that happens, then a terminal bell fires.
- Given the dashboard is running in an unfocused terminal tab or pane, when an item enters inbox or blocked, then the bell still fires.
- Given an item is already in the needs-attention bucket, when nothing new enters, then no bell fires again for that same item - only on the transition into the bucket.
