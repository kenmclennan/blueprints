## Switch to the backlog with a tab or shortcut

**Who:** Operator

**What:** A persistent tab, alongside the footer, lets me flip between current work and the backlog; also reachable via a keyboard shortcut.

**Why:** So backlog isn't hidden behind something I have to remember or hunt for.

**Activity:** See what's coming next - Know what's waiting in the backlog so nothing surprises me.

**Step:** See the todo backlog

**Status:** ready

### Acceptance Criteria

- Given I'm viewing current work, when I select the backlog tab or press its shortcut, then the backlog replaces the current view.
- Given I'm viewing the backlog, when I select the current-work tab or its shortcut, then I return to the priority list.
- Given I am several screens deep (e.g. viewing an artifact or a live log), when I press Tab, then I jump straight to whichever of current work or backlog I'm not currently in, from wherever I was.

- [wireframe-backlog.html#normal - tab strip](../wireframes/wireframe-backlog.md)

### Context

AC-3's jump from a deep screen (an open artifact, a live log) is a deliberate exception to this map's one-level-at-a-time back-navigation contract, not an extension of it - the artifact viewer and live-log screens return via Esc/← to their immediate parent only, one step at a time. Tab has to bypass that back-stack entirely and land straight on the sibling top-level view (current work or backlog), so it can't be implemented as another rung of the same navigation mechanism those deeper screens already use for Esc/←.
