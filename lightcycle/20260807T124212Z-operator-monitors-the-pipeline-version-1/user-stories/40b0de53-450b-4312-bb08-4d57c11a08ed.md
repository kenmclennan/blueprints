## Return to the node without losing position

**Who:** Operator

**What:** Closing the artifact list returns to the node's detail view (the hub).

**Why:** One level of back-navigation at a time, same contract as everywhere else.

**Activity:** Inspect one item's journey - Understand a specific item end-to-end - its artifacts, child steps, and logs - to see what happened or why it's stuck.

**Step:** Explore the artifacts on a node

**Status:** ready

### Acceptance Criteria

- Given I opened the artifact list from a node's hub view, when I close the list with Esc or ←, then the hub view reappears as it was.

### References

- [wireframe-hub.html#needs-attention-human](../wireframes/wireframe-hub.md)

### Context

The "a" shortcut ("Jump straight to a node's artifacts or log from the hierarchy") opens a node's artifact list straight from the Hierarchy tab, on a node that hasn't been opened into its hub yet - so for that entry path there's no prior hub view for Esc/← to return to in the sense this AC describes. The given clause here ("opened the artifact list from a node's hub view") only covers the other path - cycling to Artifacts within an already-open hub - and neither this story nor the shortcut story says what closing the list does when it was opened that way instead: land in the node's hub, or skip the hub and go straight back to the Hierarchy tab it was jumped from.
