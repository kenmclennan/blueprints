## Quit the dashboard

**Who:** Operator

**What:** Pressing q or Ctrl+C exits the TUI cleanly from anywhere.

**Why:** So leaving is as fast and reliable as arriving.

**Activity:** Get oriented on the pipeline - See the whole pipeline at a glance - what's active, blocked, waiting on me, and queued - the moment it changes, as long as the dashboard is running.

**Step:** Launch the dashboard

**Status:** ready

### Acceptance Criteria

- Given the dashboard is open, at any screen, when I press q or Ctrl+C, then the TUI exits cleanly, returning me to the shell.

### Context

Textual doesn't give this behaviour for free. Out of the box, "q" isn't bound to quit at all, and Ctrl+C is deliberately rebound to an action that only pops a notification naming the real quit key rather than exiting - both keys need an explicit binding as part of building this story, not just relying on framework defaults. Textual resolves an ordinary binding by walking up from whatever widget currently has focus, so on screens with a focusable widget in the chain (the Hierarchy tab's tree, the Log tab's live view, the list widgets) a plain App-level binding can be shadowed by whatever's focused at the time. Matching Textual's own default quit binding, which is marked priority so it resolves from the app down instead, is what makes quitting work "at any screen" the way the acceptance criteria requires.
