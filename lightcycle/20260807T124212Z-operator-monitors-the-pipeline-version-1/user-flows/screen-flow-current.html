Item / Node Hub

Any node - theme, item, or step - opens into this same tabbed view
  • Fixed header: identity, workflow, description, step/role/elapsed, why-escalated + jump to blocker
  • Lands on the tab matching the node's state (active → Log, human-step escalation → Artifacts, blocked/queued → Hierarchy)
Hierarchy tab
  • Root-down, always fully expanded, real ids per node
  • Current node highlighted, wherever it falls
  • Content indicator (real artifacts only); a / l jump straight to a highlighted node's Artifacts / Log
Log tab
  • Live tail if active; past log if done; "nothing to stream" for a human step
Artifacts tab
  • Listed by type, internal ones hidden
  • Select one to open it
